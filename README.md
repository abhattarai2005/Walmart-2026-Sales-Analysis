# Walmart FY2024–FY2026 Sales & E-commerce Performance Analysis

## Project Overview

This project analyzes Walmart sales and e-commerce performance from FY2024 to FY2026.

The analysis compares Walmart U.S., Walmart International, and Sam's Club U.S. using Python, Pandas, and Power BI.

## Tools Used

- Python
- Pandas
- Matplotlib
- Power BI
- PyCharm

## Key Metrics

- Total Net Sales: $706.41B
- Total E-commerce Sales: $150.40B
- FY2026 YoY Sales Growth: 4.73%
- E-commerce Share: 21.3%

## Analysis Performed

- Net sales trend analysis
- E-commerce sales trend analysis
- Sales growth analysis
- E-commerce growth analysis
- Segment contribution analysis
- Power BI dashboard development

## Dashboard

The Power BI dashboard includes:

- Fiscal Year filter
- Total Net Sales KPI
- Total E-commerce Sales KPI
- YoY Sales Growth KPI
- E-commerce Share KPI
- Net Sales Trend by Segment
- E-commerce Sales Trend by Segment
- FY2026 Net Sales by Segment
- FY2026 Sales Contribution
